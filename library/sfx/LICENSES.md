- **Source:** https://github.com/wyzowl/sfx-kit (320 sounds, 30 categories)
- **License:** CC0 1.0 Universal (public-domain dedication). No attribution is legally required; the full text is in `LICENSE-CC0-1.0.txt` in this folder.
- **Verified:** the source repo's `LICENSE` file is the CC0 1.0 Universal legal code, and its `README.md` states the sounds are free for any use, commercial or not, with no credit required.
- **Copied on:** 2026-11-25, original file names unchanged.
- **Metadata:** `catalog.json` maps each file to its category and to the `use_for` / `avoid_for` hints from the source repo. Use the catalog to pick a sound for a given job, e.g. whoosh for map zoom, impact for reveal, riser for suspense.
